Results Summary: Lupus Dataset

Author

Oktawia Miluch

Published

January 10, 2026

In this script, 4 models are considered: 3 already used in the previous scripts, namely logistic regression with L1 penalty, Random Forest, and XGBoost. The fourth model is the sparse log-contrast classification model as implemented in the R package trac version 0.0.2 (see viettr/trac GitHub repository for implementation details).

Sparse log-contrast classification model with square hinge loss: The model can be described as follows: \[ y = X \beta + \sigma \epsilon \quad \text{subject to} \quad C \beta = 0 \]

where \(y\) is a binary outcome vector, \(X\) is a predictor matrix, \(C\) is a general constraint matrix, \(\beta\) is an unknown coefficient vector and \(\sigma\) is an unknown scale parameter. In this analysis the squared hinge loss is used with an \(\ell_1\) penalty for the \(\beta\) coefficients. Therefore, the optimization problem is defined as follows:

\[ \begin{aligned} \min_{\beta \in \mathbb{R}^{d}} \quad & \sum_{i=1}^{n} \, \ell\!\left(y_i\, x_i^{\top}\beta\right) \;+\; \lambda \lVert \beta \rVert_{1} \\ \text{subject to}\quad & C\beta = 0 , \end{aligned} \]

where the \(x_i\) are the rows of \(X\), \(\lVert \beta \rVert_{1}\) is the \(\ell_1\) penalty and the loss function \(\ell(\cdot)\) is defined as:

\[ \ell(r)= \begin{cases} (1-r)^2, & \text{if } r \le 1,\\[4pt] 0, & \text{if } r \ge 1. \end{cases} \]

Given this setup, the fitted model outputs a score for each observation, which can be thresholded to obtain class predictions. To obtain probabilities, an additional step is required (e.g., additional model transforming scores into probabilities). Consequently, Brier scores are not reported for the sparse log-contrast model. The sparse log contrast model is fitted only on the original data (not augmented) and its purpose is to provide an additional benchmark for the logistic regression model with L1 penalty.

Code 
#\ label: lollipop_plot_lasso
# Lolipop plot with coefficients 
df_plot <- res$lasso |> 
  filter(aug_strategy == "aug_in_p", split_seed == 11) |> 
  select(-c(aug_factor:lambda_1se)) |> 
  unnest(beta_1se) |> 
  filter(estimate != 0, term != "(Intercept)") |>
  mutate(
      base_id = if_else(str_detect(term, "_\\d+$"),
                        str_extract(term, "(?<=_)\\d+$"),
                        "standard"),
      base = if_else(base_id == "standard",
                    "Standard ILR",
                    paste("Random ILR base", base_id)),
      coord = str_remove(term, "_\\d+$") |> str_remove("^V") |> as.integer(),
      coord_label = paste0("Coordinate ", coord)
    )

base_levels <- c(
  "Standard ILR",
  paste("Random ILR base", sort(unique(df_plot$base_id[df_plot$base_id != "standard"])))
)

df_plot <- df_plot |>
  mutate(base = factor(base, levels = base_levels)) |>
  arrange(base, desc(abs(estimate))) |>
  mutate(y = row_number())

base_bounds <- df_plot |>
  group_by(base) |>
  summarise(
    y_min = min(y),
    y_max = max(y),
    y_mid = (y_min + y_max) / 2,
    .groups = "drop"
  ) |>
  arrange(base)

sep_lines <- base_bounds |>
  mutate(y_sep = y_max + 0.5) |>
  slice_head(n = 2)

x_lab_inside <- 1
x_min <- min(df_plot$estimate, 0, x_lab_inside)
x_max <- max(df_plot$estimate, x_lab_inside)

ggplot(df_plot, aes(x = estimate, y = y, color = base)) +
  geom_segment(aes(x = 0, xend = estimate, yend = y), linewidth = 1.1) +
  geom_point(size = 3.2) +
  geom_hline(data = sep_lines, aes(yintercept = y_sep), color = "grey70") +
  geom_text(
    data = base_bounds,
    aes(x = x_lab_inside, y = y_mid, label = base),
    hjust = 0,
    fontface = "bold",
    size = 4.5,
    color = "grey20"
  ) +
  scale_y_continuous(breaks = df_plot$y, labels = df_plot$coord_label) +
  scale_color_viridis_d(option = "D", end = 0.9, guide = "none")  +
  labs(
    x = expression(paste("Estimates of ", beta, " coefficients")),
    y = NULL,
    title = "Coefficients of L1-penalized logistic regression by ILR basis",
    subtitle = "Data split: 11"
  ) +
  coord_cartesian(xlim = c(x_min, x_max)) +
  theme_bw()

Feature Importance

Feature importance is computed on the test data. For each model trained on one data split 5 ilr coordinates with the higest variable importance scores are identified. Then, for those coordinates, 3 original features that contributed most to them are identified. Below table shows original features that contribute most often to standard ILR coordiantes that achieve the highest VIMP scores. For example, feature T4_em contributes in numerator of the standard ILR coordinate that is selected by all models in nearly all data splits.
